# Html

A collection of small standalone HTML pages. Each file runs in any browser with no build step and no server.

## Pages

| File | Description |
|------|-------------|
| `Zerch.html` | Zerch, a private search page with AI overviews. No account required. |
| `Releases/0.0.1/BabylonianTime.html` | Babylonian time and date. |
| `Releases/0.0.1/Bookmarks.html` | Bookmarks page. |
| `Releases/0.0.1/Offense.html` | Lab learning dashboard. |
| `Releases/0.0.1/UniversalTime.html` | New universal time format. |

## Usage

Open the file in a browser.

## Releases

Release files are in `Releases/0.0.1/`.
